# Selecting a profile and logging out: what you will see

## The problem
When a parent opens a child's profile, there is no way to go back and pick another child, or to log out. The only way out is to close the app.

## What we will add
At the bottom of the child's **Profile page** (the page that opens when you tap the ⭐ stars button), two new buttons:

```
 ┌─────────────────────────────────┐
 │   Mia's Profile                  │
 │   ⭐ Stars, level, badges        │
 │                                  │
 │   ┌───────────────────────────┐  │
 │   │     Select Profile        │  │   -> back to "Pick your profile"
 │   └───────────────────────────┘  │
 │   ┌───────────────────────────┐  │
 │   │      Log out              │  │   -> signs the parent out
 │   └───────────────────────────┘  │
 └─────────────────────────────────┘
```

- **Select Profile** takes you back to the screen where you pick which profile to use.
- **Log out** signs the parent out, after a "Are you sure?" message.
- Same on the website and the app. On a phone the buttons are full width and easy to tap.
- They are only on the Profile page, so children don't press them by accident while playing.

## A quick question before leaving
Before either button works, a short message asks a grown-up to answer a simple question, for example **"What is 7 × 8?"**. This keeps children from logging the family out or reaching the parent settings by themselves.

## Questions for you
1. Is **"Select Profile"** and **"Log out"** the wording you want?
2. Do you want the **grown-up question**? We recommend yes.
3. Should a child be able to switch to a brother or sister **without** the grown-up question? We suggest no, because the next screen also holds the parent settings.
